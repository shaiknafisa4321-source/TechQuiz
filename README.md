#  TechQuiz with Leaderboard

##  About the Project

TechQuiz with Leaderboard is an interactive web-based quiz application developed using HTML, CSS, and JavaScript. It allows users to participate in a technical quiz, answer multiple-choice questions, receive instant feedback, view their final scores, and compare their performance through a leaderboard.

The application provides a simple and user-friendly interface for testing basic knowledge of web development and programming concepts.

##  Features

- **Player Name Entry:** Users can enter their names before starting the quiz.
- **Multiple-Choice Questions:** Includes 8 technical questions.
- **Instant Feedback:** Displays whether the selected answer is correct or incorrect.
- **Score Calculation:** Automatically calculates the final score.
- **Progress Tracking:** Shows quiz progress while answering questions.
- **Leaderboard:** Displays players ranked according to their scores.
- **Top 10 Rankings:** Shows the top 10 leaderboard entries.
- **Local Storage:** Saves quiz attempts in the browser so leaderboard data remains after refreshing.
- **Clear Leaderboard:** Allows users to clear saved leaderboard records.
- **Responsive Design:** Supports desktop and mobile-sized screens.

##  Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Quiz functionality, score calculation, and leaderboard logic.
- Browser Local Storage – Saving leaderboard records.

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, install the Live Server extension in VS Code.
6. Right-click `index.html` and select **Open with Live Server**.

##  How to Use

1. Open the TechQuiz application.
2. Enter your name.
3. Click the Start Quiz button.
4. Read each question and select an answer.
5. Click Next to continue.
6. Complete all 8 questions.
7. View your final score.
8. Check your position on the leaderboard.
9. Play again and try to achieve a higher score.

##  Note

This project uses browser Local Storage to save leaderboard records. Therefore, leaderboard data is available only in the browser and device where the quiz was played. It does not currently support a shared leaderboard across different devices.
